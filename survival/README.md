# `survival/` — shared survival-analysis utilities

Common R utilities for the time-to-event analyses used across the UK Biobank and
external cohorts.

| Folder | Contents |
| --- | --- |
| [`time2event/`](time2event/) | Time-dependent survival metrics (Brier-score decomposition, time-dependent AUC, NRI, decision-curve analysis), shared modeling routines, and publication figures. |

These utilities are sourced by the cohort-specific survival scripts in
[`../cohorts/`](../cohorts/). See the root [`README.md`](../README.md).
